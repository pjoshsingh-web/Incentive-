# Q-Line logo asset

`q-line-logo.png` is the original, unmodified artwork supplied by the user in Q-Line Trucking Logo(1).zip.

`lib/brand.ts` sets the local logo path. `app/components/qline-brand.tsx` uses the original file in the sidebar, loading screen and account screen. The sidebar uses a CSS viewport to show the Q at narrow widths; the source image is unchanged. The Q-Line red and charcoal theme is in `app/brand.css`.
